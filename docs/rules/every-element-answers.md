# every-element-answers

Each visual element states something true about the thread. If you cannot say what it states, remove it.

## Why

The air traffic theme is one step from costume. It holds only while every part carries information.

## Wrong

```
A second sweep line, or range rings that mark nothing.
```

## Right

```
One sweep line: turning means playing, still means paused.
```

## Enforcement

Prose only.
